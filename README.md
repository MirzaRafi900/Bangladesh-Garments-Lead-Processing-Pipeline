# Bangladesh Garments Lead Processing Pipeline

## Overview

A Python-based data cleaning and lead preparation project designed to process large garment and buying-house directories.

The project focuses on transforming raw business directories into structured, clean, and analysis-ready lead datasets.

---

## Features

✅ Load Excel Dataset

✅ Remove Duplicate Records

✅ Handle Missing Values

✅ Filter Usable Leads

✅ Validate Contact Information

✅ Export Clean Lead List

---

## Workflow

Raw Dataset
↓
Data Loading
↓
Data Cleaning
↓
Duplicate Removal
↓
Lead Filtering
↓
Final Lead Dataset
